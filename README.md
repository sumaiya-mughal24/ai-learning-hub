# 🎓 AI Learning Hub

An AI-powered learning assistant that helps students understand subjects and topics in a simple and easy way.

## 📚 Features

* 🎓 Multiple education levels
* 📖 Subject and topic-based learning
* 🤖 AI-generated explanations
* 💡 Simple and easy-to-understand answers
* 💻 Python examples when helpful
* 📝 Practice questions for learning
* ⚡ Fast AI responses using Groq

## 🛠️ Technologies Used

* Python
* Streamlit
* Groq API

## 🚀 How It Works

1. Select your education level.
2. Enter a subject.
3. Enter the topic you want to learn.
4. Submit your request.
5. AI Learning Hub generates an easy-to-understand explanation with examples and practice questions.

## 🔐 API Key

The Groq API key is stored securely using Streamlit Secrets and is not included directly in the source code.

## 🌐 Live App

AI Learning Hub is deployed using Streamlit Community Cloud.

## 📌 Project Purpose

The goal of AI Learning Hub is to make learning easier and more interactive by providing AI-powered explanations, examples, and practice questions for students.
